# BATRECON Portfolio 2026

Premium responsive portfolio for BATRECON / Aswin Krishnan.

Designed as two experiences rather than one layout that simply shrinks:
- Desktop: cinematic typography, hover interactions, 3D tilt, particles and spacious project layouts.
- Mobile: touch-first navigation, controlled typography, stacked project cards, compact spacing and no desktop-only cursor effects.

## Run

Open `index.html`, or use:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Main files
- `index.html` content and structure
- `style.css` responsive visual system
- `script.js` interactions and animations
- `assets/` supplied artwork
